# 🌱 Verde Fácil

Projeto desenvolvido para a **Entrega 2 da Sprint 1**, com o objetivo de facilitar o acesso a informações sobre descarte correto de resíduos e denúncias ambientais.

* 🏠 Tela inicial
* 🧭 Menu de navegação
* ♻️ Pontos de coleta
* 🚨 Denúncia ambiental
